| --- | ---: |
| L1 基础级 | 120 |
| L2 进阶级 | 60 |
| L3 高级 | 45 |
| 合计 | 225 |

## 在线阅读

本仓库通过 Docsify 发布为 GitHub Pages：

<https://zonkidd-shao.github.io/gplt_article_by_ruby/>

进入站点后，可以使用左侧导航、搜索框和题目之间的上一题 / 下一题导航浏览题解。

## 本地预览

仓库根目录就是站点根目录，使用任意静态文件服务器即可预览：

```bash
python3 -m http.server 8899
```

然后打开 <http://127.0.0.1:8899/>。

## 目录结构

- `L1-*.md`：基础级题解
- `L2-*.md`：进阶级题解
- `L3-*.md`：高级题解
- `images/`：题目详情引用的 78 张本地图片
- `index.html`：Docsify 站点入口
- `_sidebar.md`：题目导航

题解正文包含题目描述、输入输出格式、样例、实现原理、带注释的 Ruby 实现和流程图。每篇 Markdown 均直接内嵌完整代码，不依赖仓库外的运行时文件；题目描述与图片引用已整理为仓库内的相对路径，站点可直接离线浏览。
