# GPLT Ruby 题解

团队程序设计天梯赛（GPLT）练习集的 Ruby 语言题解，覆盖基础级、进阶级和高级题目。

## 内容概览

| 级别 | 数量 | 内容 |
| --- | ---: | --- |
| L1 基础级 | 120 | 基础语法、模拟与简单数据结构 |
| L2 进阶级 | 60 | 常用算法与综合应用 |
| L3 高级 | 45 | 复杂算法与较高难度综合题 |
| **合计** | **225** | **完整练习集** |

## 在线阅读

本仓库通过 Docsify 发布为 GitHub Pages：

<https://zonkidd-shao.github.io/gplt_article_by_ruby/>

在线站点支持左侧题目导航、全文搜索，以及题目之间的上一题 / 下一题切换。

## 本地预览

仓库根目录就是站点根目录。启动任意静态文件服务器即可预览：

```bash
python3 -m http.server 8899
```

然后打开 <http://127.0.0.1:8899/>。

## 文档结构

- `L1-*.md`：基础级题解
- `L2-*.md`：进阶级题解
- `L3-*.md`：高级题解
- `images/`：题目详情引用的本地图片
- `index.html`：Docsify 站点入口
- `_sidebar.md`：题目导航

每篇题解按统一结构编排：题目描述、输入输出格式、样例、实现原理、代码流程、带注释的 Ruby 实现和流程图。代码直接内嵌在 Markdown 中，题目图片使用仓库内的相对路径，站点可直接离线浏览。
